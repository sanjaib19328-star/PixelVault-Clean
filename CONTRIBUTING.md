# Contributing to PixelVault Clean

Thank you for contributing!

## Development Guidelines
- Maintain strict TypeScript typing in `frontend/src/` (no `any`).
- Follow backend service boundaries outlined in `AGENTS.md`.
- Keep dark forensic UI theme consistent (`#080B12` background, `#C8FF00` primary lime, `#00E5FF` cyan, `#FF5C35` warning orange).
- Add pytest cases for any new backend endpoint or forensic detector.
